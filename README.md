# 🏫 Sistem Informasi Pembayaran SPP (SPP Abror)

Sistem Informasi Pembayaran SPP adalah aplikasi berbasis web yang dirancang untuk mempermudah pengelolaan, pencatatan, dan pemrosesan transaksi pembayaran SPP sekolah secara terstruktur.

## ✨ Fitur Utama

- **🔐 Autentikasi Sistem:**
  - Sistem login berbasis hak akses untuk Admin dan Petugas.
- **⚙️ Manajemen Data Master (Admin):**
  - **Data Siswa:** Pengelolaan informasi data siswa (tambah, edit, hapus, detail).
  - **Data Kelas:** Pengelolaan daftar kelas dan jurusan.
  - **Data Petugas:** Pengelolaan akun petugas kasir/pengelola SPP.
  - **Data SPP:** Pengaturan nominal tarif dan periode pembayaran SPP.
- **💳 Transaksi Pembayaran:**
  - Entri dan pencatatan transaksi pembayaran SPP siswa.
  - Pemrosesan dan verifikasi bukti/status pembayaran.

## 🛠️ Teknologi yang Digunakan

- **Backend:** PHP (Native)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3
